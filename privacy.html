Privacy Policy - Rclone Backup

Purpose

Rclone Backup is a personal application used to back up Google Drive files to a local external hard drive.

Google Drive Access

The application uses the Google Drive API with read-only permission. It accesses file contents and metadata solely to perform backups.

Data Storage

Backup files are stored locally on the user's external hard drive. OAuth credentials are stored locally by Rclone.

Data Sharing

Google Drive data is not uploaded to this website, sold, or shared with third parties by this application. It is not used for advertising.

Data Retention

The user controls the retention and deletion of locally stored backup files. Google Drive access can be revoked through Google Account settings.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
